# RoboMaster Studio v0.1.0 · 快速开始

1. 将 ZIP 完整解压到固定的可写目录。
2. 双击 `Start-Studio.cmd`。项目数据保存在同目录的 `data/`。也可以直接运行 `RoboMasterStudio.exe`，这时使用当前用户的默认 AppData 数据目录。
3. 点击右上角设置，填入模型 API 基础地址、模型 ID 与 API Key。支持 Chat Completions 兼容接口及 Responses。凭据按 API 地址存入 Windows 凭据库；换地址需单独填写该地址的 Key。
4. 在设置中指定已安装的 SolidWorks MCP Python 与 `mcp-server/server.py`。上游：[solidworks-automation-skill](https://github.com/wzyn20051216/solidworks-automation-skill)。点击连接 MCP 进行工具发现。
5. 启动你现有的 RoboMaster CAD RAG 服务，默认地址 `http://127.0.0.1:8765`。step.parts 的在线检索无需本地部署。
6. 打开「设置 → 模型工作区」，输入完整目录（例如 `D:\RoboMaster\CAD`）或点击「选择文件夹」，保存后作为所有项目的模型读取、保存、导出和下载位置。目录不存在时自动创建，不可用时会提示原因。此设置重启后保留。

工作区内的已有 CAD 文件可由模型检索。下载位于 `downloads/<project-id>/`。恢复默认目录后，各项目使用原来的默认模型目录。切换只影响后续操作，不搬动已有文件，也不改变对话、规格与 skill 的存放位置。

需要 Windows 10/11 x64 与 WebView2 Runtime；原生 CAD 操作还需要正常可用的 SolidWorks 和 MCP 的 Python 依赖。本程序不包含 SolidWorks、模型 API 额度或 RAG 的原始 CAD 库。

## 五个工作阶段

- **确认组件需求**：先讨论用途与接口；右侧规格可编辑。未知值放到暂定参数；已核实零件需填写来源。
- **检索可复用组件**：切换本地 CAD RAG 与 step.parts。点击候选看来源、限制、下载工作副本或交给模型评估。
- **一次性原型机**：创建外形原型，只读取必要的几何 / 包围盒，不执行测试或工程验收。
- **建模与验收**：观察逐轮目标、修正与证据。确认实际结果后再人工验收。可总结经验为 skill。
- **添加机械配合**：点击开始，向模型注入配合指令；歧义时点选处理方式。

每类窗口右侧加号可多开。同类至少保留一个。所有窗口共享同一条对话和项目规格，输入草稿分别保留。

## 经验与设置

出现不确定操作时，用户选择会保存为情境偏好 skill，并附上选择后的实际执行记录。失败也会保留。模型总结或外部导入的 skill 可在设置中查看、编辑和启用；导入支持单个 `SKILL.md`，不执行附带脚本。

设置可以编辑五个阶段的提示词，选择墨夜、研究白、蓝图、陶土主题。默认采用墨夜，以及 OCR A Extended（英文与数字）和 Noto Sans SC Thin（中文）；已保存的主题仍保留。桌面版读取本机已安装字体，便携包不附带字体文件；缺少字体时设置页会提示并使用回退字体。人文宋体、工程等宽仍可选。机械插图的轻微视差、按钮边缘缓慢流光和面板切换动效遵循系统的「减少动态效果」设置。

对话与工具结果保存在本地，调用模型及自动总结时相关内容会发给所配置的服务。没有真实模型 Key 时可使用项目管理、规格、主题等功能；模型请求会显示配置提示。

## 失败与停止

停止会取消当前模型请求或停止后续操作。正在执行的 SolidWorks COM 操作需要返回后才能停止后续步骤。超时表示结果可能未知，先查看 SolidWorks，再去设置重连；不会自动重复执行该操作。

本版本已验证 Rust 核心流程、真实 MCP 握手、本地 RAG、step.parts 下载与桌面交互。完整的付费模型驱动 CAD 建模闭环仍需在配置你的 API 后验收。模型输出、工具返回和工程验收是不同层次，不能把原型或单次工具成功视为完整机械验收。
