# 机械工作台视觉系统

设计日期：2026-11-12（Asia/Singapore）。参考 [Nous Research 官网](https://nousresearch.com/)。

主题一致性更新：2026-11-13。

## 实际观察

本次在真实 Chromium 页面中操作鼠标、点击导航、滚轮滚动、按 Escape、切换明暗主题和展开搜索面板，检查操作前、中、后的画面；同时核对页面实际样式。当前会话未收到用户启用的 Edge 插件控制工具，因此没有声称接管用户的 Edge 标签页。研究截图留在 `.local/nous-reference/`，不进入应用或发布包。

观察到的设计语言：

- 灰白底与高饱和电光蓝，深色模式使用近黑背景；细边框、直角和反色区域组织页面。
- 窄体英文大标题与小号等宽索引形成层级；正文使用独立、易读的字体。
- 导航悬停展开下划线，点击后菜单轻微缩放并淡入，菜单项悬停反色。
- 滚动后导航收紧并保持可用；边框光带缓慢移动。
- 搜索入口展开成带插画的面板；主题切换带有 CRT / 扫描视觉。

以上是参考观察，并非把官网的字体、品牌、文案或人物图片复制到本项目。

## 本项目的转译

工作台默认采用「墨夜」：`#101018` 背景、`#b9abff` 强调色、`#e9e8f3` 正文。保留研究白、蓝图、陶土主题；既有 theme ID 和已保存的用户主题保持兼容。启动窗口和首屏也使用深色，避免加载时闪白。

主题色只在 `design.css` 的色板中定义。顶部光带、按钮流光、机械图标题、扫描光、图版背景和配合按钮均读取当前色板或其明暗派生色，不再保留固定的紫蓝色。深色图版上的强调色会适度提亮以保证对比度。机械图片通过 CSS 灰度与亮度混合适配当前图版色调，原始 PNG 不变；设置页中的主题色板样本继续展示各候选主题的配色。

默认英文与数字使用 OCR A Extended；中文使用 Noto Sans SC Thin（可变字体 `wght=100`）。桌面程序从 Windows 的系统或用户字体目录加载本机字体至内存，避免 WebView 字体集合未刷新造成的静默回退；发布包不包含这些字体文件。字体缺失时使用回退字体，设置页显示缺失提示。字体选择仍支持人文宋体与工程等宽。浏览器预览依赖浏览器自身的本机字体集合；原生字体是否正确以实际字形检查为准。

界面已去除需求、检索、配合页的中文口号，规格侧栏的重复说明，以及设置页的介绍段落。保留操作名、字段名、错误、来源、原型范围和待核实状态。机械图说明收敛为 `CONCEPT STUDY`，悬停标题仍说明它不是当前 CAD 模型。

五个横向工作阶段、结构化规格与底部输入区始终保留。缩小窗口时优先保证输入区和操作按钮可达，内容区域独立滚动。机械图标仅作为产品标识。

图片直接使用用户提供的原始 PNG，通过 CSS 排版和遮罩融合，没有改写原文件，也没有远程图片请求：

| 原始素材 | 使用位置 |
|---|---|
| `images/复古CRT故障机械爆炸图.png` | 需求阶段、机械配合阶段 |
| `images/赛博朋克爆炸式电机解析图.png` | 外形原型、建模迭代 |
| `images/复古CRT风格爆炸电路板结构图.png` | 双源检索、设置侧栏 |

没有人物、人物雕塑或人物局部素材。未复制官网商业字体；显示标题和中文正文使用本机字体回退，无需联网加载字体。

## 动效规范

| 交互 | 实现 |
|---|---|
| 工作阶段切换 | 420 ms 淡入与 8 px 向上归位 |
| 项目菜单展开 | 220 ms 淡入、轻微缩放，原点位于左上 |
| 设置打开 / 设置分页 | 300–350 ms 淡入与短距离归位 |
| 导航标签悬停 | 下划线展开；加号轻转；活动阶段反色 |
| 按钮悬停 / 键盘聚焦 | 450 ms 淡入的 1 px 边缘光带，4.8 s 绕行一周；不覆盖文字，禁用按钮不发光；原有导航反色与下划线保留 |
| 输入框聚焦 | 边线变为强调色，左侧出现窄色条 |
| 机械插图 | 鼠标驱动最多约 ±5 px / ±3.5 px 的轻微视差；移出归位；悬停单次弱扫描 |
| 顶部边框 | 20 s 缓慢光带移动，不改变布局 |
| 减少动态效果 | 遵循 `prefers-reduced-motion`，关闭动画、过渡、视差与平滑滚动，包括伪元素 |

持续文本闪烁与高频故障闪屏没有用于正文、参数或输入区。
