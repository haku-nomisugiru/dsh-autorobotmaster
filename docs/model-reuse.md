# 下载模型的打开、检查与复用评估

在“模型库”检索候选，查看来源及验证状态。原生装配通常需要完整模型包才能保留相对引用。下载过程校验 SHA-256。

点击“打开已下载模型并检查”后，工作台在独立目录准备副本，依据哈希定位入口，保留原生文件名与目录结构。原生文件以只读方式打开，STEP 导入为新文档。检查报告包含当前配置、组件树、引用配置、加载和抑制状态、包内缺失引用、同名歧义和包外引用。当前模型与包内其他文件分别统计。组件结构检查以当前配置为准。

“AI评估当前下载”将所选模型的来源、当前配置、组件名、依赖及验证摘要发送到所配置的模型 API。专门入口省略绝对本机路径、CAD 文件内容和无关对话。能否复用还需核对目标安装接口、载荷、空间和运动约束。

过去的现场验收覆盖两个样本。一个 STEP 悬挂模型可读取 87 个组件。一个原生抓取装配只下载入口时出现 3 条缺失引用，下载完整包后该装配的 3 个组件均加载。上述结果对应已测样本和配置。

| 方法 | 本机路径 | 用途 |
| --- | --- | --- |
| POST | /api/library/open | 按 JSON 字段 id 发起异步准备、打开和检查 |
| GET | /api/library/inspection | 读取检查状态、结构和评估结果 |
| POST | /api/library/assess | 发起当前模型复用评估，可传 target_requirements |

这些接口沿用工作台的本机 token 验证。准备和 COM 调用期间阻止新的前台 CAD 任务。若调用超时，先检查任务状态再重试。
